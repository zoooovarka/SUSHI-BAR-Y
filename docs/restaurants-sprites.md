Меню каждого ресторана собрано из четырёх типов станций:

| Тип станции | Как работает | В суши-баре |
|---|---|---|
| `assembly` (сборка) | основа → добавки → тап по слоту (готовится N секунд) | роллы, мисо |
| `fryer` (жарка/варка) | тап по заготовке → готовится → снять вовремя, иначе сгорит | темпура |
| `brew` (вскипятить и налить) | тап по ёмкости → нагрев → тап по пустой посуде наливает порцию | чай |
| `trash` | мусорка | мусорка |

В каждом ресторане 7 блюд на 10 уровней.

## Общие правила для картинок

- PNG с прозрачным фоном, без свечения вокруг (если свечение есть, я его срежу), стиль как у листа «ингредиенты и суши».
- Присылать можно листами: я нарежу и назову файлы сам.
- «Неправильные» блюда (`*_wrong.png`) рисовать не нужно, их я делаю из готового блюда: обесцвечиваю и перечёркиваю.
- Посетители общие для всех ресторанов (6 персонажей уже есть).
- Иконки улучшений — 128×128, в стиле листа «глянцевые иконки улучшений кухни», удобнее всего листом 3×3.
- Иконки зала общие для всех ресторанов: терпение ✅, чаевые ✅, «Официант» ✅.
