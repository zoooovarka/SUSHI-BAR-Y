# Спрайты для новых ресторанов

Меню каждого ресторана собрано из тех же четырёх типов станций, что и в суши-баре, поэтому для запуска нужны только картинки и запись в `CONFIG.restaurants`:

| Тип станции | Как работает | В суши-баре |
|---|---|---|
| `assembly` (сборка) | основа → добавки → тап по слоту (готовится N секунд) | роллы, мисо |
| `fryer` (жарка/варка) | тап по заготовке → готовится → снять вовремя, иначе сгорит | темпура |
| `brew` (вскипятить и налить) | тап по ёмкости → нагрев → тап по пустой посуде наливает порцию | чай |
| `trash` | мусорка | мусорка |

В каждом ресторане 7 блюд на 10 уровней, как в суши-баре.

## Общие правила для картинок

- PNG с прозрачным фоном, без свечения вокруг (если свечение есть, я его срежу), стиль как у листа «ингредиенты и суши».
- Присылать можно листами: я нарежу и назову файлы сам.
- «Неправильные» блюда (`*_wrong.png`) рисовать не нужно, их я делаю из готового блюда: обесцвечиваю и перечёркиваю.
- Посетители общие для всех ресторанов (6 персонажей уже есть).

### Для каждого ресторана нужен набор окружения

| Файл | Что это |
|---|---|
| 1 картинка интерьера (как «Уютный японский суши-бар») | зал со стойкой на переднем плане и пустой столешницей внизу; я режу её на `bg_hall_X.jpg`, `counter_X.jpg`, `bg_kitchen_X.jpg`, `bg_levels_X.jpg` |
| `rest_X.png` | иконка ресторана для шапки и окна уровня (домик или главное блюдо) |

Ниже X — это `ramen`, `wok`, `dimsum`, `sweets`.

## Иконки улучшений (желательно, иначе будут эмодзи)

В каждом ресторане свой набор улучшений: скорость сборки, число слотов, скорость и слоты жарки, ёмкость напитка, цены трёх групп блюд. Иконки зала (терпение, чаевые, «Официант») общие. На ресторан нужно около 8 иконок по 128×128 в стиле листа «глянцевые игровые иконки», например для раменной: `up_ramen_slots`, `up_broth_speed`, `up_pan_speed`, `up_pan_slots`, `up_boil_slots`, `up_jug`, `up_price_ramen`, `up_price_sides`.

Точные имена файлов иконок назову, когда буду добавлять ресторан в CONFIG: они зависят от того, какие улучшения окажутся у его станций.
