# Звуки

Сюда кладутся музыка и звуковые эффекты. Все файлы необязательны: если файла нет, музыка не играет, а эффект синтезируется прямо в игре, как раньше.

Формат — **mp3**: он работает во всех браузерах, включая iPhone. Имена файлов и громкость задаются в `CONFIG.audio` в `index.html`.

| Файл | Где звучит | Советы |
|---|---|---|
| `music_map.mp3` | карта, уровни ресторана, магазин | спокойный лоуфай, 60–90 BPM, 1–2 минуты, бесшовная петля |
| `music_game.mp3` | во время уровня | бодрее, 110–130 BPM, 1,5–2 минуты, бесшовная петля |
| `yooo.mp3` | победа на уровне, вместе с окном звёзд | 1–2 секунды, без тишины в начале |

- Музыка зацикливается: конец трека должен переходить в начало без щелчка и паузы.
- Размер: 128 кбит/с, стерео или моно. Минута такой музыки весит около 1 МБ.
- Громкость: музыку делать заметно тише эффектов; игра дополнительно приглушает её (`musicVolume`), а на время «YOOOO» — ещё сильнее (`duck`).
- Вариантов «YOOOO» может быть несколько: `sfx: { win: ['yooo.mp3', 'yooo2.mp3'] }` — каждый раз играет случайный.
- Любой другой звук игры тоже можно заменить файлом, добавив его в `sfx`. Имена звуков: `click`, `place`, `ready`, `serve`, `coin`, `heart`, `combo`, `bad`, `trash`, `burn`, `angry`, `bell`, `win`, `lose`, `ach`, `tick`.
- На время рекламы, в свёрнутой вкладке и при выключенном звуке музыка и эффекты замолкают (это требование Яндекс Игр).
- Для Яндекс Игр звук должен быть своим или с лицензией, разрешающей коммерческое использование: выкрик из чужого видео или мема может не пройти модерацию.
