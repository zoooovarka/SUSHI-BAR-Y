# Мяу-суши

Кулинарный тайм-менеджмент для Яндекс Игр. Кот-шеф открывает рестораны азиатской кухни: гости-коты делают заказы у стойки, игрок готовит и подаёт блюда, пока у гостя не кончилось терпение.

Весь код — один файл `index.html` (HTML + CSS + JS, без сборщиков и библиотек). Картинки кладутся в `img/`; если файла нет, вместо него рисуется эмодзи-заглушка, так что игра работает и без графики.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
```

Локально `/sdk.js` отсутствует, поэтому игра работает на заглушках SDK: сохранения в `localStorage`, реклама за вознаграждение имитируется секундной заставкой, полноэкранная реклама пропускается.

Для загрузки в Яндекс Игры: заархивируйте `index.html` и папку `img/` (в корне архива). В консоли разработчика создайте лидерборд с техническим именем `stars` (имя задаётся в `CONFIG.leaderboard`).

## Как устроено

- **Отрисовка — DOM-элементы**, а не canvas: браузер сам определяет, по какому элементу пришёлся тап. Сцена 1600×900 (16:9) масштабируется `transform: scale` под любой экран, в портретной ориентации на телефоне игра встаёт на паузу и просит повернуть устройство.
- **Ввод**: игровые действия срабатывают на `pointerdown` (без задержки, работает мультитач), кнопки интерфейса — на `click`. Перетаскивания нет.
- **CONFIG** описывает спрайты, рестораны, блюда, станции, рецепты, улучшения и все 20 уровней. Станции бывают четырёх типов (`assembly` — циновки со сборкой, `fryer` — фритюр, `dispenser` — кастрюля/чайник, `trash` — мусорка), и логика работает только по этим типам. Новый ресторан добавляется записью в `CONFIG.restaurants`. Параметр станции может быть числом или id улучшения, тогда значение берётся с текущей ступени.
- **Тексты** на русском и английском лежат в объекте `TEXT`, язык берётся из `ysdk.environment.i18n.lang`.

## Механики

- Циновки: тап по нори кладёт основу, тап по начинке кладёт её на первую основу без неё, тап по основе скручивает ролл (2 с). Несовпадающее сочетание даёт «неправильный» ролл, его можно только выбросить.
- Фритюр: креветка жарится 5 с, после этого её нужно снять тапом в течение 6 с, иначе она сгорит (штраф 5 монет при выбрасывании). Снятая темпура сразу уходит гостю, а если её никто не ждёт — на поднос.
- Мисо и чай наливаются сами (3 с за порцию) до вместимости кастрюли или чайника.
- Мусорка: тап включает режим выбрасывания, следующий тап по циновке, корзине или подносу выбрасывает содержимое. Сгоревшее и неправильное выбрасывается и обычным тапом.
- Блюдо отдаётся гостю, который ждёт дольше всех. Если блюдо никому не нужно, оно трясётся. Оплата приходит за весь заказ целиком, чаевые: +50% при терпении выше 66%, +20% при терпении выше 33%. Каждые 3 гостя подряд без потерь дают комбо +15.
- Уровни 1–3 обучающие (рука-указатель). На уровнях, где появляется новое блюдо, рука подсказывает, пока это блюдо не подадут первый раз.

## Баланс

Пороги звёзд подобраны прогоном бота: он играет по той же логике, что и рука-подсказка, по 3 раза на уровень в 5 профилях (реакция 0,6 с или 1,0 с; без улучшений, с первой ступенью всех улучшений, с полными улучшениями). Для 1★ хватает медленной игры без улучшений, для 2★ нужна быстрая игра, для 3★ на поздних уровнях нужны и скорость, и улучшения.

Режим отладки: `index.html?debug&bot&speed=10&botdt=0.6` — бот играет сам, `speed` ускоряет время, `botdt` задаёт паузу между его действиями в секундах. В обычном запуске ничего из этого не включено.
